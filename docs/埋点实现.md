 可以设计成一个渠道适配器模式：前端业务代码只调用统一的埋点方法，不直接关心不同渠道需要什么参数；不同渠道的参数差异交给各自的
  Adapter 处理。

  核心思路：

  track(eventName, baseParams)

  业务方只传通用参数，内部根据当前渠道自动补充、转换、过滤参数。

  ———

  推荐结构
```js
  type Channel = 'wechat' | 'alipay' | 'app' | 'h5';

  type BaseTrackParams = {
    userId?: string;
    page: string;
    buttonName?: string;
    orderId?: string;
    [key: string]: any;
  };

  type TrackPayload = {
    eventName: string;
    params: Record<string, any>;
  };

  interface TrackAdapter {
    buildPayload(eventName: string, params: BaseTrackParams): TrackPayload;
    send(payload: TrackPayload): void;
  }
```
  ———

  不同渠道实现自己的适配器
  ```js
  class WechatTrackAdapter implements TrackAdapter {
    buildPayload(eventName: string, params: BaseTrackParams): TrackPayload {
      return {
        eventName,
        params: {
          event_id: eventName,
          openid: params.userId,
          page_path: params.page,
          btn_name: params.buttonName,
          order_id: params.orderId,
          channel: 'wechat',
        },
      };
    }

    send(payload: TrackPayload) {
      wx.reportAnalytics(payload.eventName, payload.params);
    }
  }

  class AlipayTrackAdapter implements TrackAdapter {
    buildPayload(eventName: string, params: BaseTrackParams): TrackPayload {
      return {
        eventName,
        params: {
          seedId: eventName,
          uid: params.userId,
          pageName: params.page,
          actionName: params.buttonName,
          bizOrderId: params.orderId,
          source: 'alipay',
        },
      };
    }

    send(payload: TrackPayload) {
      my.aplus_queue.push({
        action: 'aplus.record',
        arguments: [payload.eventName, 'CLK', payload.params],
      });
    }
  }

  class H5TrackAdapter implements TrackAdapter {
    buildPayload(eventName: string, params: BaseTrackParams): TrackPayload {
      return {
        eventName,
        params: {
          event: eventName,
          user_id: params.userId,
          page: params.page,
          button_name: params.buttonName,
          order_id: params.orderId,
          channel: 'h5',
        },
      };
    }

    send(payload: TrackPayload) {
      window.collectEvent?.(payload.eventName, payload.params);
    }
  }
```
  ———

  统一埋点入口
```js
  const adapters: Record<Channel, TrackAdapter> = {
    wechat: new WechatTrackAdapter(),
    alipay: new AlipayTrackAdapter(),
    h5: new H5TrackAdapter(),
    app: new H5TrackAdapter(),
  };

  function getCurrentChannel(): Channel {
    if (/MicroMessenger/i.test(navigator.userAgent)) return 'wechat';
    if (/AlipayClient/i.test(navigator.userAgent)) return 'alipay';
    return 'h5';
  }

  export function track(eventName: string, params: BaseTrackParams) {
    const channel = getCurrentChannel();
    const adapter = adapters[channel];

    if (!adapter) {
      console.warn(`[track] unsupported channel: ${channel}`);
      return;
    }

    const payload = adapter.buildPayload(eventName, params);
    adapter.send(payload);
  }
```

```js

  if (isAlipay) {}
  if (isApp) {}
```
  所有差异都被收敛到渠道适配器里。

  我建议的最终方案

  - 渠道少、只是字段名不同：用配置映射方案。
  - 渠道多、发送方式也不同：用适配器模式。
  - 字段名不同 + SDK 调用方式不同：适配器模式里再结合参数映射。

  最实用的结构是：

  track()
    -> 获取当前渠道
    -> 找到对应 adapter
    -> adapter 转换参数
    -> adapter 调用对应渠道 SDK

  这样后续新增渠道时，只需要新增一个 XxxTrackAdapter，不需要改业务代码。

  ———

  实现方式
```js
  function useUniversalTrack(options) {
    const {
      title,
      rules,
      trackFn,
    } = options;

    return function track(params) {
      const {
        channel,
        productType,
        eventName,
        ...extraParams
      } = params;

      const allowedTypes = rules[channel];

      if (!allowedTypes) {
        return;
      }

      if (!allowedTypes.includes(productType)) {
        return;
      }

      const finalParams = {
        title,
        channel,
        productType,
        ...extraParams,
      };

      if (typeof trackFn === 'function') {
        trackFn(eventName, finalParams);
        return;
      }

      console.log('埋点上报:', eventName, finalParams);
    };
  }
```
  ———

  调用示例
```js
  const trackInstallment = useUniversalTrack({
    title: '埋点文案',
    rules: {
      h5: ['01'],
      wechat: ['01', '02'],
    },
    trackFn(eventName, params) {
      // 替换成你们真实的埋点方法
      window.track?.(eventName, params);
    },
  });
```
