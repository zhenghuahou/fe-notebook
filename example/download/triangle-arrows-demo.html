核心代码示例

🔹 Border 方法（最常用）

/* 向上箭头 */
.triangle-up {
  width: 0;
  height: 0;
  border-left: 10px solid transparent;
  border-right: 10px solid transparent;
  border-bottom: 15px solid #333;
}

/* 向右箭头 */
.triangle-right {
  width: 0;
  height: 0;
  border-top: 10px solid transparent;
  border-bottom: 10px solid transparent;
  border-left: 15px solid #333;
}

🔹 Clip-path 方法（现代浏览器）

/* 向上箭头 */
.clip-triangle-up {
  width: 20px;
  height: 20px;
  background-color: #333;
  clip-path: polygon(50% 0%, 0% 100%, 100% 100%);
}

/* 向右箭头 */
.clip-triangle-right {
  width: 20px;
  height: 20px;
  background-color: #333;
  clip-path: polygon(100% 50%, 0% 0%, 0% 100%);
}

🔹 Transform Rotate 方法（线条风格）

/* 基础样式 */
.rotate-arrow {
  width: 10px;
  height: 10px;
  border-top: 2px solid #333;
  border-right: 2px solid #333;
  display: inline-block;
}

/* 不同方向 */
.rotate-arrow.up { transform: rotate(-45deg); }
.rotate-arrow.right { transform: rotate(45deg); }
.rotate-arrow.down { transform: rotate(135deg); }
.rotate-arrow.left { transform: rotate(-135deg); }
选择建议：
  • Border方法：兼容性最好，适合大多数场景
  • Clip-path方法：现代浏览器推荐，支持复杂形状
  • Transform方法：适合线条风格的箭头
  • Unicode方法：最简单，但定制性有限
