CSS Safe Area 安全区域详解

🎯 代码解释

这段代码的作用：

为元素添加底部安全区域内边距，确保内容不被设备的物理特征（如 iPhone 的 Home Indicator）遮挡。

.van-safe-area-bottom { /* iOS 11.0-11.2 版本支持 */ padding-bottom: constant(safe-area-inset-bottom); /* iOS 11.2+ 和其他现代浏览器支持 */ padding-bottom: env(safe-area-inset-bottom); }
为什么写两行？
因为 CSS 的层叠特性，浏览器会使用它支持的最后一个有效值。老版本 iOS 支持 constant()，新版本支持 env()。

📱 什么是安全区域 (Safe Area)

安全区域是指屏幕中不会被设备物理特征遮挡的区域，主要包括：

iPhone X 系列

  • 顶部刘海 (Notch)
  • 底部 Home Indicator
  • 圆角屏幕边缘

Android 设备

  • 状态栏
  • 导航栏
  • 异形屏切口

其他设备

  • 折叠屏铰链
  • 摄像头挖孔
  • 物理按键区域

🔧 CSS 环境变量详解

环境变量 含义 常用场景 示例值
safe-area-inset-top 顶部安全区域距离 状态栏、刘海区域 44px (iPhone X)
safe-area-inset-bottom 底部安全区域距离 Home Indicator 34px (iPhone X)
safe-area-inset-left 左侧安全区域距离 横屏时的刘海 44px (横屏)
safe-area-inset-right 右侧安全区域距离 横屏时的刘海 44px (横屏)

💡 实际应用示例

1. 底部导航栏

.bottom-navigation { position: fixed; bottom: 0; left: 0; right: 0; background: #fff; padding: 10px; /* 关键：添加底部安全区域 */ padding-bottom: calc(10px + constant(safe-area-inset-bottom)); padding-bottom: calc(10px + env(safe-area-inset-bottom)); }

2. 全屏弹窗

.fullscreen-modal { position: fixed; top: 0; left: 0; right: 0; bottom: 0; /* 四个方向都考虑安全区域 */ padding-top: constant(safe-area-inset-top); padding-top: env(safe-area-inset-top); padding-bottom: constant(safe-area-inset-bottom); padding-bottom: env(safe-area-inset-bottom); padding-left: constant(safe-area-inset-left); padding-left: env(safe-area-inset-left); padding-right: constant(safe-area-inset-right); padding-right: env(safe-area-inset-right); }

3. 页面容器

.page-container { min-height: 100vh; padding: 20px; /* 确保内容不被底部遮挡 */ padding-bottom: calc(20px + constant(safe-area-inset-bottom)); padding-bottom: calc(20px + env(safe-area-inset-bottom)); }

4. Vant UI 组件库的实现

/* Vant 提供的工具类 */ .van-safe-area-top { padding-top: constant(safe-area-inset-top); padding-top: env(safe-area-inset-top); } .van-safe-area-bottom { padding-bottom: constant(safe-area-inset-bottom); padding-bottom: env(safe-area-inset-bottom); } .van-safe-area-left { padding-left: constant(safe-area-inset-left); padding-left: env(safe-area-inset-left); } .van-safe-area-right { padding-right: constant(safe-area-inset-right); padding-right: env(safe-area-inset-right); }

✅ 最佳实践

1. 设置 viewport

viewport-fit=cover 是启用安全区域的关键

2. 渐进增强

.element { /* 基础样式 */ padding-bottom: 20px; /* 安全区域增强 */ padding-bottom: calc(20px + env(safe-area-inset-bottom)); }

3. CSS 自定义属性

:root { --safe-area-inset-bottom: env(safe-area-inset-bottom); } .element { padding-bottom: var(--safe-area-inset-bottom); }

4. JavaScript 检测

// 检测是否支持安全区域 const supportsSafeArea = CSS.supports('padding-bottom', 'env(safe-area-inset-bottom)'); if (supportsSafeArea) { document.body.classList.add('supports-safe-area'); }

❓ 常见问题

Q: 为什么在桌面浏览器中不生效？

A: 安全区域主要针对移动设备，桌面浏览器中这些值通常为 0。

Q: 如何在开发时测试安全区域？

A: 使用 Chrome DevTools 的设备模拟器，选择 iPhone X 等设备进行测试。

Q: 可以用 margin 代替 padding 吗？

A: 可以，但要注意 margin 塌陷等问题。padding 通常更安全。

Q: 如何处理横屏情况？

A: 使用 safe-area-inset-left 和 safe-area-inset-right。

🎯 总结

.van-safe-area-bottom 这段代码的核心作用是：

  • 为元素添加底部安全区域内边距
  • 确保内容不被 iPhone 的 Home Indicator 等遮挡
  • 兼容不同版本的 iOS 系统
  • 提升移动端用户体验
