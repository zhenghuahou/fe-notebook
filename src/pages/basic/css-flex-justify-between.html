🎯 核心要点总结

基础属性

  • display: flex
  • justify-content: space-between
  • align-items: center

常见场景

  • 导航栏布局
  • 卡片头部/底部
  • 表单行布局
  • 左右分组显示

注意事项

  • 考虑响应式设计
  • 处理内容溢出
  • 合理使用 gap 属性
  • 注意垂直对齐
